# Cloud-Native DevOps Platform

An end-to-end DevOps project demonstrating the deployment and operation of a containerized application using cloud infrastructure, Infrastructure as Code, Kubernetes, CI/CD, security scanning, and monitoring.

## Project Goals

- Build a REST API
- Containerize the application with Docker
- Provision cloud infrastructure using Terraform
- Deploy the application to Kubernetes
- Automate CI/CD using GitHub Actions
- Implement security scanning
- Monitor the application using Prometheus and Grafana
